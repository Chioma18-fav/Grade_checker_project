# Grade Checker 📝

This is a Python project I built as part of my programming coursework. 
You enter a student's name, course, and score and the program tells 
you what grade they got.

## How It Works

The program asks for three things:
- The student's name
- The course name  
- The student's score (must be between 0 and 100)

It then checks the score against the grading scale and prints the result:

If you enter something that isn't a number, or a number outside 0–100, 
the program will ask you to try again.
